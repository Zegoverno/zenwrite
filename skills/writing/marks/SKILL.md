# Marks

Point at possible improvements without changing the note.

- Use only `weak` (vague, flat, passive, or says little), `long` (hard to follow in one breath), and `filler` (words that add nothing).
- `find` is exact, one line, and occurs once. For weak or long marks use the sentence; for filler use only the removable words.
- Never mark headings, names, quotations, citations, numbers, links, or code.
- Marks never overlap. Return at most 25, most useful first; a strong piece can have few.
- `why` is under eight words and in the note's language.
