# Changelog line

Write one factual line for a reader returning to the note later.

- Say what changed, not how much: name the section or kind of change.
- Use fewer than 12 words, lowercase start, no final period, date, or version number.
- For several changes, name the main one first; put small typo fixes last.
- Match the note's language. Do not praise the change or guess its motivation.
