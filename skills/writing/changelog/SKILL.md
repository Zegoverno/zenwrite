# Changelog line

One line that says what changed in this version of the note, for the writer reading the changelog
months later.

## Rules

- What changed, not how much: "added the angels section", "tightened the opening", "fixed
  typos". Name the parts of the piece that moved.
- Under 12 words, lowercase start, no final period, no date or version number (the app adds them).
- Several changes: the main one first, then "and …"; small fixes go last ("…, and typo fixes").
- In the note's language.
- Plain and factual: never praise the change, never guess why.

## Your preferences

Add a line when a pattern is clear from the lines you accept or rewrite; newest last.
